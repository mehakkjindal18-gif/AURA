About the project

What is being predicted

Here, personality classification means a binary label: Introvert or Extrovert. The labels in the dataset come from self-reported answers about everyday social behaviour.

Behaviour indicators such as time alone, stage fear, event attendance and friend-circle size are easy to answer and easy to measure. A model learns how combinations of these answers tend to line up with each label across many respondents.

The project is educational and analytical. It shows how a short questionnaire becomes a trained, evaluated classifier that is served through a web API.

Understanding the models

Two classifiers, compared

Logistic Regression

Weighs each scaled answer, adds the results together, and squeezes the total into a probability between 0 and 1. It is fast and easy to interpret, but it draws a single straight boundary between the classes.

Random Forest

Builds many decision trees on random samples of the data and averages their votes. It can capture combinations of answers that a single straight boundary misses.

Both were compared because a simple, interpretable baseline shows whether extra complexity is worth it. Their test accuracies are very close. Random Forest powers the live prediction because it ranks the two classes better than Logistic Regression (higher ROC-AUC on the test set) and provides per-feature importances.

Limitations

  • The model learns patterns from self-reported questionnaire data.
  • Predictions depend on the dataset and its quality.
  • The model does not capture every dimension of human personality.
  • This is an educational machine learning demonstration, not a validated psychological or clinical assessment.
